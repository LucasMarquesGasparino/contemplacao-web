Contemplação

Imagens em tela cheia para respirar um pouco. Sem anúncios, sem pressa.

  • Toque na imagem ou use › contemplar para a próxima.
  • Arraste para o lado ou use as setas do teclado.
  • Escolha o som em loop — chuva, cachoeira, mar, gaivotas, floresta, cidade… tudo bem sutil, para não competir com a imagem.
  • Use auto para troca automática a cada 18s.
  • Botão — esconde a interface para contemplação pura. Toque na imagem para trazer de volta.

Fontes de imagens — sem direitos autorais restritivos

  • Pixabay — fotos e paisagens CC0 (https://pixabay.com) — natureza, cidade, mar, floresta
  • Unsplash CDN direto — 30+ fotografias contemplativas licença gratuita (images.unsplash.com)
  • Metropolitan Museum of Art (Met) — obras em domínio público via Collection API (https://metmuseum.github.io) — fantasia e obras-primas
  • Wikimedia Commons — obras-primas domínio público (Van Gogh, Hokusai, Monet, Friedrich)
  • Picsum Photos — fallback CC0 (https://picsum.photos) — quando online

Sons gerados localmente com Web Audio (ruído filtrado + osciladores) + previews Pixabay CC0 quando online. Tudo em loop perfeito, sem cortes bruscos.

Dica: deixe o brilho no mínimo e o volume baixo. É para desacelerar.
